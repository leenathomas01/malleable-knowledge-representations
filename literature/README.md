# Relevant literature — connections, not proof

**Status:** Selected primary-source starting points; not a systematic review. Paper details and quantitative claims should be verified before formal publication. None demonstrates the entire MKR proposal.

| Research thread | Primary source | Relevance and limitation |
| --- | --- | --- |
| Library induction | [DreamCoder — Ellis et al.](https://arxiv.org/abs/2006.08381) | Learned program abstractions and search guidance; task-family and symbolic-language constraints. |
| Program refactoring | [Librarian](https://arxiv.org/abs/2506.11058) | Reusable abstractions from multiple programs; applicability and reported numerical gains need independent replication. |
| Option reuse | [Sutton, Precup & Singh (1999)](https://doi.org/10.1016/S0004-3702(99)00052-1) | Temporally extended actions; not arbitrary mutable latent knowledge. |
| MDL-based program library | [Stitch](https://arxiv.org/abs/2211.16605) | Compression-driven abstraction extraction; does not show unconstrained representational restructuring. |
| Concept subspaces | [Vector Arithmetic in Concept and Token Subspaces](https://arxiv.org/abs/2511.18162) | Geometric operations in selected subspaces; not general compositional validity. |
| Cross-model latent mappings | [Thinking in Different Spaces](https://arxiv.org/abs/2603.20406) | Mappings and interventions; geometric alignment is not sufficient for behavioral correction. |
| Modular adaptation | [LoRA — Hu et al.](https://arxiv.org/abs/2106.09685) | Localized efficient weight updates; not proof of reinterpretation of existing knowledge. |
| Hidden capabilities | [Emergence of Hidden Capabilities](https://arxiv.org/abs/2406.19370) | Elicitation constraints inside implemented networks; not unrealized ideas. |
| Task arithmetic | [Editing Models with Task Arithmetic](https://arxiv.org/abs/2212.04089) | Weight-space combination; composition and transfer are conditional. |
| Bisimulation | [Towards Robust Bisimulation Metric Learning](https://arxiv.org/abs/2110.14096) | Behavior-relevant equivalence; task and metric constraints apply. |
| Quality diversity | [MAP-Elites](https://arxiv.org/abs/1504.04909) | Diversity-preserving exploration baseline; not intrinsically dynamic partition revision. |

## Research gap to test, not to assume

Does an optional, learned or designed *representational restructuring* step provide a budget-adjusted advantage beyond capable existing refactoring, extra search, and latent reuse in a domain requiring shifts in useful decomposition?

## Bibliographic hygiene

Use exact methods and conditions, not analogies, to infer support. Links are literature leads; any detailed numerical claim must be checked in its source. Record negative comparisons and conflicting results.
